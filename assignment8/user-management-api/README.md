# Job Portal API

Express and MongoDB backend for the Admin & Employee Job Portal.

Setup, environment variables, the API reference, security notes and testing are documented in the
[root README](../../README.md).

## Commands

Run these from this folder (`assignment8/user-management-api`):

```bash
npm install     # install dependencies
npm run dev     # start the API with nodemon (needs .env, see the root README)
npm start       # start the API with node
npm run seed    # local sample data and logins (local database only)
npm test        # run the 98 backend tests (in-memory database, never reads .env)
```
